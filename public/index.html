Global pricing settings

Configure hourly print costs, profit and tax for Print Library sell prices.
Sell prices include current filament cost, the slicer-estimated print time multiplied by the hourly rate, and sundries for one complete print. Profit markup or margin is applied to those costs; the configured tax rate is added afterwards. Prices are shown including tax, per sale lot (and in total), with currency-appropriate rounding. Leave the profit percentage blank to disable sell price estimates. The hourly rate uses each file's filament currency. Set 0 to exclude print time costs. For a non-zero rate, a slicer print duration is required; items without one cannot show a Sell price. Other costs not covered by this rate, such as shipping or labour, can be added as sundries. Use 0% if no tax should be added. This is a pricing estimate, not a tax return.

FARM PROTECTION

Backup & recovery

Create a portable backup of controller configuration, Print Library content, queue/history and related persistent state.
Manual backup
The controller builds and verifies the backup before it is offered for download.
Backup files may contain printer credentials, Print Library files and your signed licence. Backups are integrity-checked but are not encrypted; store them only in a trusted location.
Google Drive
Connect a Google account using Google's device authorization flow. Backups are stored in a controller-managed Print Farm Controller Backups folder using limited per-file Drive access.

Custom credentials are stored with controller data and take precedence over the built-in application credentials. The client secret is never displayed again after saving.

S3-compatible storage
Store backups in an S3-compatible bucket such as MinIO, Amazon S3, Cloudflare R2, Backblaze B2 or Wasabi. The controller uses Signature Version 4 and keeps credentials only in controller data.
S3 connection configuration
Enter the S3 endpoint, bucket and credentials supplied by your storage provider. Use path-style addressing for MinIO and most S3-compatible services; virtual-hosted addressing is available for providers that require it.
Leave the secret access key blank when saving an unchanged access key. Enable insecure HTTP only for a trusted local service such as a development MinIO instance.
Scheduled backups
Save verified backups automatically to a local/NAS destination, Google Drive, Microsoft OneDrive or configured S3-compatible storage.
Retention applies only to scheduled backups created by this controller installation at the selected destination. Manual backups and backups from other installations are never pruned.
Restore inspection
Validate a .pfcbackup and review what it contains. Inspection never changes controller data.
Local and cloud backups use the same inspection, validation and staged restore pipeline. A valid inspection enables restore staging. The staged restore activates only after Print Farm Controller is restarted; unfinished jobs remain recovery-held until deliberately rechecked.
