S3-compatible storage
Store backups in an S3-compatible bucket such as MinIO, Amazon S3, Cloudflare R2, Backblaze B2 or Wasabi. The controller uses Signature Version 4 and keeps credentials only in controller data.
S3 connection configuration
Enter the S3 endpoint, bucket and credentials supplied by your storage provider. Use path-style addressing for MinIO and most S3-compatible services; virtual-hosted addressing is available for providers that require it.
Leave the secret access key blank when saving an unchanged access key. Enable insecure HTTP only for a trusted local service such as a development MinIO instance.
Scheduled backups
Save verified backups automatically to a local/NAS destination, Google Drive, Microsoft OneDrive or configured S3-compatible storage.
Retention applies only to scheduled backups created by this controller installation at the selected destination. Manual backups and backups from other installations are never pruned.
Restore inspection
Validate a .pfcbackup and review what it contains. Inspection never changes controller data.
Local and cloud backups use the same inspection, validation and staged restore pipeline. A valid inspection enables restore staging. The staged restore activates only after Print Farm Controller is restarted; unfinished jobs remain recovery-held until deliberately rechecked.
