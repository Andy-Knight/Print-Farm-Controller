CONTROLLER DATA

Backup & recovery

Create a portable backup of controller configuration, Print Library content, queue/history and related persistent state.
Manual backup
The controller builds and verifies the backup before it is offered for download.
Backup files may contain printer credentials, Print Library files and your signed licence. v0.23.0 backups are integrity-checked but are not encrypted; store them only in a trusted location.
Scheduled backups
Save verified backups automatically to a local folder, mapped drive or writable UNC/NAS path.
Retention applies only to scheduled backups created by this controller installation. Manual backups and backups from other installations are never pruned.
Restore inspection
Validate a .pfcbackup and review what it contains. Inspection never changes controller data.
A valid inspection enables restore staging. The staged restore activates only after Print Farm Controller is restarted; unfinished jobs remain recovery-held until deliberately rechecked.
